# 데이터 소스 정책

| 공급자 | 용도 | 저장 방식 |
| --- | --- | --- |
| Jolpica | 캘린더·결과·순위 | 정규화 후 Supabase 캐시 |
| OpenF1 | 세션·타이어·위치·날씨·레이스 컨트롤 | 라이브 상태 + 필요한 스냅샷 |
| YouTube Data API | 공식 채널 영상 발견 | 메타데이터와 video ID만 저장 |
| FIA Media Centre | 기자회견 출처·일정 | URL·메타데이터·개인용 요약 |
| Pirelli | 주말 지정 컴파운드 | 사실 데이터만 자체 UI로 표시 |

모든 레코드에는 `source_id`, 원본 URL, 원본 게시 시각, 수집 시각을 유지한다. 비공식 재업로드 채널은 영상 allowlist에 넣지 않는다.
