## 제한과 미검증

- 공개 SignalR은 TimingData·TimingAppData·TimingStats·CurrentTyres·TyreStintSeries·RaceControlMessages·TeamRadio 등을 제공했지만 Position.z·CarData.z는 수신하지 않았다. 위치 0·차량 0이다.
- OpenF1 세션 API와 공식 Position.z 정적 경로는 각각 HTTP 401을 반환했다. 공개 피드 연결 자체는 live다. 이 제한을 수집기 전체 장애 또는 시간대 오류로 묶으면 안 된다. 접근 우회나 유료 가입은 하지 않았다.
- 따라서 선수 좌표·속도·RPM·기어·스로틀·브레이크의 경기 중 연속 갱신은 **실패/제한**이다. 공식 맵만 표시하는 안내는 정상이다. 실시간 트랙맵 전체 성공을 주장하지 않는다.
- 경기 중 OpenF1 기반 랩 비교는 선수 선택 비활성 및 '세션 결과를 불러오지 못했습니다'로 표시됐다. 접근 제한에 맞는 설명 개선과 세션 종료 후 복구 확인이 남았다.
- 연습 세션의 전역 LapCount는 미제공이며 화면은 —/—다. 타이어 사용 랩을 경기 전체 랩수로 바꿔 표시하면 안 된다.
- Mac 상시 워커는 로컬 저장 키 미등록으로 미설치다. 현재 지속 저장은 GitHub 러너가 맡는다. 예약 시작 지연 문제는 여전히 남아 있다.
